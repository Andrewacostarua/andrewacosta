1
Identify the firm's ATS (Applicant Tracking System)

Visit the firm's careers page and look at the URL. Each ATS has a recognizable pattern:

URL patternATSScraper file
boards.greenhouse.io/… or boards-api.greenhouse.ioGreenhousescrapers/greenhouse.py
*.myworkdayjobs.comWorkdayscrapers/workday.py
jobs.lever.co/…Leverscrapers/lever.py
*.smartrecruiters.com or api.smartrecruiters.comSmartRecruitersscrapers/smartrecruiters.py
*.icims.comiCIMSscrapers/icims.py
jobs.jobvite.com/…Jobvitescrapers/jobvite.py
jobs.ashbyhq.com/… or any JS-rendered pageAshby / Customscrapers/playwright_scraper.py

If the careers page renders job listings in JavaScript with no clear ATS URL, use Playwright.

2
Add the firm to the right scraper file

Open the appropriate file and add one entry to the FIRMS list. The format depends on the ATS:

# scrapers/greenhouse.py — need the board slug (part after /boards/) { "firm": "Firm Name", "slug": "firmslug", "tier": "target", "track": "repe" } # scrapers/workday.py — need subdomain + jobsite slug from the Workday URL { "firm": "Firm Name", "subdomain": "firmname", "jobsite": "FirmCareers", "wdver": "wd1", "tier": "target", "track": "repe" } # scrapers/playwright_scraper.py — just need the careers page URL { "firm": "Firm Name", "url": "https://firmname.com/careers", "tier": "target", "track": "repe", "bot_protected": False }

Finding Workday slugs: the Workday URL looks like firmname.wd1.myworkdayjobs.com/en-US/FirmCareers — subdomain is firmname, jobsite is FirmCareers.

Finding Greenhouse slugs: visit boards.greenhouse.io/SLUG and try the firm's name, hyphenated name, or ticker until one works.

3
Add the firm to MASTER_FIRMS in scraper.py

This is what makes the firm appear as "Not Open Yet" on the dashboard when no roles are found. Without this step, the firm is invisible.

# scraper.py → MASTER_FIRMS list { "name": "Firm Name", "tier": "target", "track": "repe", "careers_url": "https://firmname.com/careers" }

The name must exactly match the "firm" field in the scraper entry — this is how open roles get linked to their firm.

4
Understand which roles get included automatically

The scraper filters every posting against these rules. No manual curation needed — if the title passes, it appears on the dashboard.

Title must contain analyst or associate AND at least one of:

real estateinvestment bankingcapital marketsacquisitionsprivate equityinfrastructureasset managementportfoliocreditunderwritingtransactionequitydebtfundsecuritiesmultifamilyfinancialstructuredoriginationvaluationnet leaseinvestor relations

Title must NOT contain any of:

seniorvice presidentdirectormanaging directorprincipaltechnology analystdata analystsystems analystcompliance analystlegal analystmarketing analystbusiness analystgovernance analystworkforcepayoffprocurement

To change these rules, edit EXCLUDE_TERMS and RELEVANT_TERMS in scrapers/utils.py — one file, applies to all scrapers.
